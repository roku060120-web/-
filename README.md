# 今日の授業をDiscordに自動投稿（Google Apps Script版）

毎日 **12:00（日本時間）** に、その日の授業一覧を Discord に自動投稿します。
Google Apps Script で動くので、GitHubもGoogle Cloudの鍵も不要。

## 仕組み
```
Googleスプレッドシート（非公開のまま）
  ├─ 時間割マスター … 曜日・時間・講師・生徒・教科
  └─ 例外マスター   … 日付・種別(休講/振替)・講師・生徒・時間・教科
        │ Apps Scriptが読む（オーナー権限で直接）
        ▼
  今日の授業を計算（休講を除く / 振替・追加を足す）→ Discordに投稿
```

## セットアップ（1回だけ）
1. [script.google.com](https://script.google.com) → 新しいプロジェクト
2. `apps-script/Code.gs` の中身を貼り付けて保存
3. 関数 `postToday` を実行 → 初回だけ承認（自分のGoogleで許可）
4. Discordに出たら成功。`setupNoonTrigger` を1回実行 → 毎日12:00の自動投稿ON

## 入力するスプレッドシート
| シート | 列 |
|---|---|
| 時間割マスター | `曜日, 時間, 講師, 生徒, 教科` |
| 例外マスター | `日付, 種別, 講師, 生徒, 時間, 教科` |

例外の書き方：
- **休講**：日付・「休講」・講師・生徒
- **振替**：①元の日に「休講」＋②移動先の日に「振替」（時間・教科も記入）
- **追加**：日付・「追加」・講師・生徒・時間・教科
