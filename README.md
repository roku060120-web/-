# 今日の授業をDiscordに自動投稿

毎日 **12:00（日本時間）** に、その日の授業一覧を Discord に自動投稿します。
入力は **Googleスプレッドシート**、実行は **GitHub Actions（無料）**。

## 仕組み
```
Googleスプレッドシート（非公開のまま）
  ├─ 時間割マスター … 曜日・時間・講師・生徒・教科
  └─ 例外マスター   … 日付・種別(休講/振替)・講師・生徒・時間・教科
        │ サービスアカウントで読み取り（Sheets API）
        ▼
GitHub Actions（毎日12:00）
  → 今日の授業を計算（休講を除く / 振替・追加を足す）
  → Discord に投稿
```

## 入力するスプレッドシート
| シート | 列 |
|---|---|
| 時間割マスター | `曜日, 時間, 講師, 生徒, 教科` |
| 例外マスター | `日付, 種別, 講師, 生徒, 時間, 教科` |

例外の書き方：
- **休講**：日付・「休講」・講師・生徒（その日その授業を消す）
- **振替**：①元の日に「休講」＋②移動先の日に「振替」（時間・教科も記入）
- **追加**：日付・「追加」・講師・生徒・時間・教科

## 初回セットアップ（1回だけ）
1. **Googleサービスアカウント**を作成し、鍵(JSON)をダウンロード（手順は別途）
2. 2つのスプレッドシート（または「T DX」フォルダ）を、そのサービスアカウントのメールアドレスに **閲覧者** で共有
3. GitHubの **Settings → Secrets and variables → Actions** に登録：
   - `DISCORD_WEBHOOK` … DiscordのWebフックURL
   - `GOOGLE_SERVICE_ACCOUNT_JSON` … 鍵JSONの中身をそのまま貼り付け
4. **Actions** タブ →「今日の授業をDiscordに投稿」→ **Run workflow** でテスト

以降は毎日12:00に自動投稿。手動投稿も同じ **Run workflow** ボタンで可能。

## ファイル
| ファイル | 役割 |
|---|---|
| `post_schedule.py` | スプレッドシートを読み、今日の授業をDiscordへ投稿 |
| `requirements.txt` | 依存ライブラリ |
| `.github/workflows/daily-discord.yml` | 毎日12:00に実行 |
