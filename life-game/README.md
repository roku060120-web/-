# LIFE GAME // TACTICAL OPS

人生をMMOのように管理するミリタリー風HUDアプリ。
ビルド不要・依存ゼロの静的アプリ（HTML + CSS + vanilla JS）で、データは端末の `localStorage` に保存されます。

## 起動方法

**A. Windows：`LifeGame.bat` をダブルクリック（推奨）**

追加インストールは不要です（Windows標準のPowerShellだけで動きます）。

1. `LifeGame.bat` をダブルクリック
2. 黒いウィンドウが開き、ブラウザで `http://127.0.0.1:8971/` が自動的に開きます
3. 閉じるときは黒いウィンドウを閉じます

`127.0.0.1`（自分のPC）だけで待ち受けるので、**外部からは接続できません**。

デスクトップにショートカットを置くと1クリックで起動できます
（`LifeGame.bat` を右クリック → 送る → デスクトップ（ショートカットを作成））。
さらに、ブラウザで開いたあと Chrome / Edge の「…」メニュー →
「アプリとしてインストール」を選ぶと、独立したウィンドウのアプリになります。

サーバが起動できなかった場合は、自動的に `standalone.html` を開きます（機能は同じです）。

**B. 1ファイル版をダウンロードして開く（いちばん簡単）**

`life-game/standalone.html` は HTML・CSS・JS を1枚にまとめたファイルです。
これをダウンロードしてダブルクリックすれば、そのままブラウザでアプリが動きます。

**C. リポジトリをクローンして開く**

```bash
git clone https://github.com/roku060120-web/-.git
cd -/life-game

open index.html                 # macOS （Windows は start、Linux は xdg-open）

# もしくはローカルサーバ経由（データ保存が確実に効くのでおすすめ）
python3 -m http.server 8080     # → http://localhost:8080
```

GitHub Pages 等にそのまま置いても動きます。

### 1ファイル版のビルド

`index.html` / `css` / `js` を編集したら、以下で `standalone.html` を作り直します。

```bash
cd life-game && python3 build-standalone.py
```

## 2つのフェーズ

```
①登録フェーズ（ENLISTMENT）        ②メインフェーズ
初回起動時のみ。8ステップで基本情報を入力  →  3画面のダッシュボード
```

初回起動すると登録フェーズが開きます。入力するのは以下で、**必須は6項目**だけです。

| STEP | 内容 | 必須 |
|---|---|---|
| 01 OPERATOR | コールサイン / 学年 / 学期 | コールサイン・学年・学期 |
| 02 AFFILIATION | 大学・学部・学科・専攻 / 入学年度 / 卒業予定 | 入学年度・卒業予定 |
| 03 RECORDS | 卒業要件と履修実績（解析済みデータがあれば自動） | — |
| 04 SUPPLY | 現在の残高 / 目標金額 / 収入源 | 残高 |
| 05 ORGANIZATIONS | サークル・部活など | — |
| 06 NETWORK | 最初の関係者（名前と所属だけ） | — |
| 07 RHYTHM | 目標睡眠時間 / 記録方法 | — |
| 08 CONFIRM | 確認して配属 | — |

STEP 04・05 で入力した収入源と組織が、**そのままタスクや予定の「属性」になります**
（「バイト1」ではなく「コンビニ」「軽音サークル」と表示されます）。

登録し直したいときは、画面左上のコールサインをタップ → `RESET` と入力します。

### 解析済みデータ（data/preset.js）

成績表PDFや履修案内の解析は**アプリの外**で行い、結果を `data/preset.js` に置く方式です。
このファイルがあると、登録フェーズの STEP 03 で「解析済みデータを使う」が選べ、
卒業要件のバケツごとの充足状況が自動で計算されます。
個人データなので `.gitignore` で除外されており、リポジトリには含まれません。

## 画面構成（左スワイプで遷移）

```
[01 STATUS] ──左スワイプ──▶ [02 OPERATIONS] ──左スワイプ──▶ [03 NETWORK]
```

操作方法：画面を横にスワイプ / ドラッグ、下部のページボタン、`←` `→` キー。

### 01 STATUS（状況報告）
- **FUNDS / 所持金** … 収支をログとして記録。直近7日の増減と目標額に対する進捗バー。
- **CREDITS / 取得済み単位** … 取得単位 / 卒業要件、達成率バー。
- **HEALTH / 平均睡眠時間** … 直近7日の平均。7h以上 GREEN / 6h以上 AMBER / それ未満 RED。7日分のログをグラフ表示。
- **WEEKLY SCHEDULE / 週次スケジュール** … 曜日別のコマ表示。当日の列はアンバーで強調。`+ ADD` で追加、コマをタップで編集・削除。
- 下部に「クリア済み任務数 / 進行中 / 締切48時間以内」のカウンタ。

### 02 OPERATIONS（タスク）
- タスクはタイトルのリスト表示。タップでトグル展開し、詳細を表示。
- 左のチェックボタンでタスクが消失（クリア数 +1）。
- 右下の `+` から追加。詳細項目は **締切日 / 内容 / 必要なもの / 完了条件 / 属性 / 重要度**。
  - 属性：`バイト1` `バイト2` `バイト3` `サークル` `大学` `ノーマル`
  - 重要度：`必須` `サブ` `余暇`
- 重要度 → 締切日の順に自動ソート。重要度チップで絞り込み可能。
- 展開後の `EDIT` で編集、`ABORT` でクリア扱いにせず削除。

### 03 NETWORK（人物関係図）
- 自分（SELF NODE）を中心に、各人物ノードがエッジで接続されたネットワーク図（力学レイアウト + レーダー演出）。
- ノードをタップすると下のカードに **連絡先 / 年齢 / 自分との関係性** を表示。ノードはドラッグで移動可能。
- 右下の `+` から人物を追加。所属（家族 / 大学 / バイト / サークル）で色分け。
- 背景を横にドラッグすればページ送り、ノードを掴んだときだけグラフ操作になります。

## データについて

保存先は起動方法によって変わります。

- **`LifeGame.bat` 経由（ローカルサーバあり）** — `data/state.json`（このPC内のファイル）が正のデータ。
  `127.0.0.1` の中だけで完結し、インターネットには一切送信されません。ブラウザの
  `localStorage`（キー: `lifegame.v2`）は書き込み直後の即時キャッシュ兼フォールバックとして併用します。
- **`standalone.html` を直接開く / サーバなし** — `localStorage` のみに保存されます（従来通り）。
- **ログインした場合** — 右上の `☁ LOGIN` からメールアドレスでマジックリンクログインすると、
  上記に加えてクラウド（Supabase, 自分専用の行のみ・RLSで他人からは不可視）にも同期されます。
  他の端末で同じメールアドレスでログインすれば、続きを見られます。ログインしなくてもアプリは
  今まで通りローカルだけで動きます（任意機能）。

初回起動時はデモデータが入っています。初期化したい場合は、コールサインをタップして `RESET` と入力するか、
コンソールで：

```js
Store.reset()   // デモデータに戻す（サーバ稼働中なら data/state.json も上書きされる）
localStorage.removeItem('lifegame.v2')   // ブラウザ側のキャッシュだけ完全に消す場合
```

`data/state.json` 自体を消したい場合は、アプリを閉じてから `data/state.json` を直接削除してください。

HUD左上のコールサインをタップすると名前を変更できます。
