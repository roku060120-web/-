# 大学 出席記録システム

授業がある日の **18:00 に iPhone にポップアップ** が出て、その日出席した授業をタップで選ぶ。
選んだ結果はスプレッドシートに溜まり、科目ごとの **出席率・あと何回休めるか** が自動で出る。

> 塾スケジュール（`apps-script/` `juku-schedule/`）とは完全に別のプロジェクト。
> 新しい Apps Script プロジェクト＋新しいスプレッドシートで動く。

## 仕組み

```
iPhone ショートカット（時刻オートメーション 18:00・毎日）
    │  ① 「今日 授業ある？」        GET ?action=today
    ▼
Google Apps Script ウェブアプリ
    │  学年暦（開講期間内か）
    │  特別日程（全学休講日 / 曜日振替）
    │  履修科目（曜日・時限で抽出）
    │  科目変更（休講を消す・補講を足す）
    ▼
  授業0件 → ショートカットは何も出さずに終了
  授業あり → 科目リストを返す
    │
    ▼
  「リストから選択」で複数選択のポップアップ
    │  ② 選んだものを送信          GET ?action=save&attended=A|B
    ▼
  出席記録シートに1行ずつ書く（選ばなかった科目は自動で「欠席」）
    → 履修状況シートを再集計 → 結果を通知で表示
```

## シート構成（`setupSpreadsheet` が自動で作る）

| シート | 列 | 用途 |
|---|---|---|
| **履修科目** | `科目コード, 科目名, 曜日, 時限, 開始, 終了, 教室, 教員, 開講期, 欠席上限` | 時間割マスター |
| **学年暦** | `開講期, 開始日, 終了日` | 開校期間。ここに入っていない日は授業なし扱い |
| **特別日程** | `日付, 種別, 実施曜日, メモ` | 種別は `休講日`（全学休み）か `曜日振替`（例: 火曜だけど月曜授業） |
| **科目変更** | `日付, 科目コード, 種別, 時限, メモ` | 種別は `休講`（その科目だけ休み）か `補講`（その日に追加） |
| **出席記録** | `日付, 曜日, 時限, 科目コード, 科目名, 状態, 記録日時` | ショートカットが書く。手で直してもOK |
| **履修状況** | 自動生成 | 科目ごとの集計ダッシュボード |

`状態` は `出席` / `欠席` / `公欠` / `遅刻`。ショートカットが入れるのは出席か欠席だけなので、
公欠・遅刻にしたい行はスプレッドシート側で書き換える（集計は次回更新時に追従する）。

`欠席上限` を入れておくと、履修状況シートに **残り欠席可能回数** と判定（✅🟡⚠️❌）が出る。空欄なら判定しない。

## セットアップ

### 1. Apps Script 側

1. [script.google.com](https://script.google.com) → 新しいプロジェクト（名前は「大学 出席記録」など）
2. `Code.gs` の中身を全部貼り付けて保存
3. 関数 **`setupSpreadsheet`** を実行 → 初回だけ Google の承認が出るので許可
   → 実行ログに新しいスプレッドシートの URL が出る。**サンプル行を自分の時間割に書き換える**
4. 関数 **`setupToken`** を実行 → ログに `API_TOKEN = xxxxx` が出る。**これをメモ**
5. 関数 **`testToday`** を実行 → 今日の授業一覧が JSON で出れば OK
   （今日が授業日じゃないときは `testDate_('2026-05-11')` のように日付を指定して確認）

### 2. ウェブアプリとしてデプロイ

1. 右上 **デプロイ** → **新しいデプロイ** → 歯車 → **ウェブアプリ**
2. 設定：
   - 次のユーザーとして実行： **自分**
   - アクセスできるユーザー： **全員**
3. デプロイ → 出てきた **ウェブアプリ URL をメモ**（`https://script.google.com/macros/s/..../exec`）
4. 関数 **`showShortcutUrls`** を実行すると、ショートカットに貼る URL がログにまとめて出る

> ⚠️ `Code.gs` を書き換えたら、**デプロイ → デプロイを管理 → 鉛筆 → バージョン「新バージョン」→ デプロイ**
> をしないと URL 側に反映されない（よくハマるところ）。

### 3. iPhone ショートカット「今日の出席」

ショートカット App → 新規ショートカット → 以下を上から順に追加。

| # | アクション | 設定 |
|---|---|---|
| 1 | **URLの内容を取得** | URL に `<ウェブアプリURL>?action=today&token=<API_TOKEN>` <br> メソッド: GET |
| 2 | **辞書の値を取得** | キー `count` ／ 取得元「URLの内容」 |
| 3 | **if** | 「辞書の値」が **数値** **0** と等しい → **ショートカットを停止** |
| 4 | *（if の「その他の場合」に以下を入れる）* | |
| 5 | **辞書の値を取得** | キー `prompt` ／ 取得元「URLの内容」 |
| 6 | **辞書の値を取得** | キー `labels` ／ 取得元「URLの内容」 |
| 7 | **リストから選択** | 入力＝手順6の結果 ／ **複数を選択：オン** ／ プロンプト＝手順5の結果 |
| 8 | **テキストを結合** | 入力＝「選択された項目」 ／ **カスタム区切り記号** に `\|` （縦棒1つ） |
| 9 | **URLの内容を取得** | URL に `<ウェブアプリURL>` ／ メソッド: GET ／ **「URLをクエリで拡張」** に3つ追加 <br> `action` = `save` <br> `token` = `<API_TOKEN>` <br> `attended` = 手順8の「結合されたテキスト」 |
| 10 | **辞書の値を取得** | キー `text` ／ 取得元「URLの内容」 |
| 11 | **通知を表示** | 手順10の結果 |

ポイント：

- **日付は送らない**。サーバー側が「今日」を使うので、ショートカットに日付処理は不要
- 手順7で**何も選ばずに「完了」**すると、その日は全科目「欠席」で記録される（サボった日はこれで一瞬）
- 同じ日にもう一度走らせると**古い記録を消して上書き**する。押し間違えたらやり直せばいい

### 4. 18:00 のオートメーション

ショートカット App → **オートメーション** タブ → 右上 **+**

1. **時刻** を選ぶ
2. **18:00** ／ **毎日**
3. 「今日の出席」を実行
4. **「実行前に尋ねる」をオフ**

> 授業がない日（開講期間外・全学休講日・その曜日に授業なし）は手順3の if で止まるので、
> **何も表示されずに静かに終わる**。毎日オートメーションを走らせて問題ない。

> 📱 iOS のバージョンや集中モードによっては、対話アクション（リストから選択）を含むショートカットが
> オートメーションから自動起動せず、通知バナーが出るだけのことがある。
> その場合は「実行前に尋ねる」を **オン** に戻すと、通知をタップ → リストが開く、という確実な動きになる。

## おまけのショートカット

### 「あとから記録」（付け忘れた日を埋める）

上の手順1と9の URL に `&date=<日付>` を足すだけ。日付は次の2アクションで作る。

1. **入力を要求** ／ タイプ: **日付**
2. **日付をフォーマット** ／ カスタム ／ 形式 `yyyy-MM-dd`

これを手順1・9の `date` クエリに渡す。付け忘れた日は `?action=missing&token=...` で一覧が取れる
（履修状況シートの下にも「未記録の日」として出る）。

### 「履修状況」（今どれくらいヤバいか見る）

1. **URLの内容を取得** … `<ウェブアプリURL>?action=summary&token=<API_TOKEN>`
2. **辞書の値を取得** … キー `text`
3. **クイックルック**

```
✅ OK 線形代数I　出席10/11　あと3回休める
🟡 注意 英語コミュニケーション　出席8/11　あと1回休める
❌ 欠席超過 プログラミング演習　出席6/11　あと-1回休める
```

## API リファレンス

すべて `token` が必須（`setupToken` で発行した値）。GET でも POST（JSON body）でも同じ。

| action | パラメータ | 返すもの |
|---|---|---|
| `today` | `date`（省略時は今日） | `{count, labels[], lessons[], prompt, open, reason}` |
| `save` | `date`, `attended`（`\|` 区切りのラベル） | `{saved, present, absent, text}` |
| `summary` | — | `{subjects[], text, danger[], warn[]}` |
| `missing` | — | `{dates[]}` 授業があったのに未記録の日 |

`attended` に含まれなかった科目は自動的に `欠席` で記録される。

## Apps Script の関数

| 関数 | いつ使う |
|---|---|
| `setupSpreadsheet` | 最初に1回。スプレッドシートを作る |
| `setupToken` | 最初に1回。APIトークンを発行する |
| `setupDailyTrigger` | 最初に1回。毎晩23:30の自動集計をON |
| `showShortcutUrls` | デプロイ後。ショートカットに貼る URL を出す |
| `refreshDashboard` | 手動で集計し直したいとき |
| `testToday` / `testDate_('2026-05-11')` | 授業判定の動作確認 |
| `testSummary` / `testMissing` | 集計・未記録日の確認 |

## ローカル検証

`node univ-attendance/test/local-test.js` で、GAS の API をスタブして授業判定ロジックを走らせられる。
通常授業 / 全学休講日 / 曜日振替 / 科目休講 / 補講 / 開講期間外 / 通年科目 / 同日再記録の上書き を確認している。
Apps Script 側には push されない（`.claspignore` で除外）。
