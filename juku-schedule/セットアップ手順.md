# 塾スケジュール一元化テンプレート — セットアップ手順

マンツーマン塾の「全講師スケジュールの一元化」を、**Googleスプレッドシート＋Google Apps Script**だけで実現する雛形です。サーバー不要・無料。

## 📦 この雛形の中身

| ファイル | 役割 |
|---|---|
| `塾スケジュール雛形.xlsx` | スプレッドシート本体（5タブ・ドロップダウン付き） |
| `Code.gs` | 自動化スクリプト（今日の授業生成・週間ビュー・Discord投稿） |
| `セットアップ手順.md` | この手順書 |

## 🧭 全体の考え方

```
① 担当マスター（講師×生徒×曜日×時間＝真実の元データ）
② 例外（休講・振替・追加）
        │  Apps Scriptが自動生成
        ▼
③ 今日の授業  ④ 週間ビュー  →（毎朝）Discordへ自動投稿
```

**固定枠（毎週同じ）**が前提なので、日々の手入力はほぼゼロ。担当が変わった時だけ①を直します。

---

## 手順1：スプレッドシートに読み込む

1. `塾スケジュール雛形.xlsx` を **Googleドライブにアップロード**
2. そのファイルを右クリック →「アプリで開く」→ **Googleスプレッドシート**
3. 開いたら メニュー **ファイル →「Googleスプレッドシートとして保存」**（xlsxのままでも動きますが、変換推奨）

タブが5つあります：`設定` / `① 担当マスター` / `② 例外` / `③ 今日の授業` / `④ 週間ビュー`

## 手順2：設定タブに講師・生徒・教科を登録

`設定` タブの各列（講師・生徒・教科・場所）に、実際の名前を**縦に追加**します。
ここに足した内容が、各タブのドロップダウンにそのまま出ます。

> 💡 生徒・講師が多い塾向けのコツ：**各講師に「① 担当マスター」の自分の行だけ入力してもらう**と、全員で手分けして一気に埋まります。固定枠なので登録は基本1回きり。

## 手順3：担当マスターを埋める（分担入力）

`① 担当マスター` に、1レッスン＝1行で入力します。

| 列 | 内容 | 例 |
|---|---|---|
| 講師 / 生徒 | ドロップダウンから選択 | 田中先生 / 生徒A |
| 曜日 / 開始 / 終了 | 固定枠の曜日・時間 | 月 / 17:00 / 18:30 |
| 教科 / 場所 | ドロップダウン | 数学 / 教室 |
| 隔週 | 毎週／A週／B週 | 毎週 |
| 有効開始日 / 有効終了日 | 担当の期間（終了は空でOK＝継続中） | 2026/04/01 / （空） |

薄黄色の「例」の行は、参考にしたら消してOKです。

## 手順4：スクリプトを貼り付ける

1. メニュー **拡張機能 → Apps Script** を開く
2. 最初からある `コード.gs` の中身を**全部消して**、`Code.gs` の内容を**丸ごと貼り付け**
3. 上部の `CONFIG.DISCORD_WEBHOOK_URL` に、後述のDiscord Webhook URLを入れる（Discord通知が不要なら空のままでOK）
4. **保存**（フロッピーアイコン）
5. スプレッドシートの画面を**再読み込み**すると、上部に **「塾スケジュール」メニュー**が出ます

> 初回だけ「承認が必要です」と出ます → 自分のGoogleアカウントで許可してください。

## 手順5：動作確認

メニュー **塾スケジュール** から：

- **今日の授業を生成** → `③ 今日の授業` に本日分（例外反映済み）が並ぶ
- **週間ビューを更新** → `④ 週間ビュー` に全担当が曜日・時間順で並ぶ

---

## 📣 Discord通知の設定（任意）

1. Discordの投稿したいチャンネル → **⚙ 設定 → 連携サービス → ウェブフック → 新しいウェブフック**
2. **ウェブフックURLをコピー**
3. `Code.gs` の `CONFIG.DISCORD_WEBHOOK_URL` に貼り付けて保存
4. メニュー **今日の授業を Discord に投稿** でテスト
5. メニュー **毎朝6時の自動投稿をON** を押すと、毎朝自動で「今日の授業」が流れます

投稿イメージ：
```
📅 本日 7/22(水) の授業
━━━━━━━━━━━━
・17:00-18:30　田中先生 / 生徒A / 数学（教室）
・19:00-20:30　佐藤先生 / 生徒B / 英語（オンライン）【振替】
```

---

## 🔧 運用ルール（例外の入れ方）

`② 例外` タブに、その日限りの変更を記録します。

| やりたいこと | 入力 |
|---|---|
| **休講**（その日だけ休み） | 日付・種別「休講」・講師・生徒 |
| **振替**（別日へ移動） | ①元の日に「休講」1行　＋　②移動先の日に「振替」1行（時間・教科・場所も記入） |
| **追加**（単発の追加授業） | 日付・種別「追加」・講師・生徒・時間・教科・場所 |

`③ 今日の授業` はこの例外を自動で反映します（休講は消え、振替・追加は入る）。

## ❓よくある質問

- **隔週授業は？** … `隔週` 列で「A週/B週」を選択。A週＝ISO週番号が奇数の週（`Code.gs` の `CONFIG.BIWEEKLY_ODD_LABEL` で入れ替え可能）。
- **Notionでも見たい** … まずはこのスプレッドシートを“真実の元”にして、Notion側はTable/Timelineで参照する構成にできます（次フェーズで連携スクリプトを追加可能）。
- **manabieとの関係** … スケジュールはこのシートで完結。manabieは指導報告書の作成に専念、という切り分けです。
